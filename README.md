## 手动安装

1. 克隆仓库：

   ```bash
   git clone https://github.com/ShukebtAb/cchaha-pet-naiwa
   ```

2. 打开 CChaha App，进入 **Settings → Pets → Custom pets → Open folder**。
3. 将仓库中的 `naifrog` 文件夹复制到打开的目录。
4. 返回 CChaha App，点击 **Refresh**，然后选择奶蛙。
